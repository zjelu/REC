

Eventloop → Poller → Channel


Eventloop::loop()
    ↓
Poller::poll()调用一次epoll_wait
    ↓
返回本轮就绪的Channel
    ↓
EventLoop逐个调用Channel::handleEvent()
    ↓
Channel根据revents调用read/write/error/close回调
    ↓
回调最终进入Acceptor或Connection


1. 
listen fd产生EPOLLIN
    ↓
Poller返回listen Channel
    ↓
Channel调用read callback
    ↓
Acceptor::handleRead()
    ↓
accept新连接

2. 客户端 fd 则是：
client fd产生EPOLLIN
    ↓
Poller返回client Channel
    ↓
Channel调用read callback
    ↓
Connection::handleRead()


## Acceptor 和 Connection 直接构造自己的 Channel
Acceptor::Acceptor(
    Eventloop* loop,
    int listen_fd
)
    : listen_fd_(listen_fd),
      listen_channel_(loop, listen_fd)
{
}
Connection::Connection(
    Eventloop* loop,
    int client_fd
)
    : client_fd_(client_fd),
      client_channel_(loop, client_fd)
{
}

## 回调是怎样完成抽象的？

Acceptor::Acceptor(
    Eventloop* loop,
    int listen_fd
)
    : listen_fd_(listen_fd),
      listen_channel_(loop, listen_fd)
{
    listen_channel_.setReadCallback(
        [this] {
            handleRead();
        }
    );
}
